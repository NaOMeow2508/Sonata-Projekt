# Sonata 项目资料库

这是 Claude Code、Codex 与项目开发者共用的知识与协作资料库，不是 App 源码仓库，也不替代原有两个仓库。

## 阅读顺序
1. PROJECT_CONTEXT.md：目标、范围及实现边界。
2. PROJECT_STATUS.md：基线、验证结果及未验收事项。
3. ASSET_INDEX.md：源码、备份与外部资料的位置和来源。
4. AGENTS.md / CLAUDE.md：协作约定。

## 分类目录
- 01_Curriculum：A1 词汇与融合课程资料。
- 02_Episodes/E01_Waste_Sorting：第一集剧本、分镜、词汇、练习、生成提示词。
- 03_Visual_Assets：Sonata、儿童、场景与品牌资料。
- 04_Research：融合、儿童发展与学习科学证据。
- 05_Website：展示文案与设计参考。
- 06_Collaboration：决策、任务与交接记录。

目录目前为空，仅建立结构；未导入图片、PDF 或剧本。未创建 Git 仓库、远程或部署配置。

## 记录规范
新资料应注明：标题、来源路径或链接、提供者、日期、版本、确认状态、适用范围及版权/使用许可（如涉及素材）。
状态统一使用：已确认背景 / 当前源码已确认 / 基线验证通过 / 待开发 / 待导入 / 待开发者确认 / 待验收。
历史聊天只作线索，不能替代源码或执行结果。文件存在不代表内容已审定。

## 协作建议
任务、决策与交接分别放入 06_Collaboration 对应目录。每次交接记录目标仓库、起止 Commit、改动文件、验证命令与结果、遗留问题。
同一源码工作目录避免同时写入；开始前检查当前 Git 状态，不把基线时的干净状态当作实时状态。
跨目录资料库的规则不会自动传播到源码仓库；操作源码前仍需阅读目标仓库适用的说明，并遵守本次授权范围。

初次进入时先只读以上文档，报告理解和缺失信息，等待开发者安排具体任务。
